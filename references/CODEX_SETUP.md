# Codex 本地接入（v1.1.3）

此流程适用于能读取项目 `AGENTS.md`、已安装本 Skill、拥有本地 Python 和所需文件工具的 Codex 宿主。纯聊天界面或不接受项目配置的客户端不支持本地跨会话恢复；不要据此宣称所有 Codex/其他客户端自动支持。无需新增插件、数据库、后台进程或独立运行时。

私人绝对路径及含恢复许可、实际能力的本地接入配置不应直接提交到公开 Git 仓库。将含私人配置的 AGENTS.md 保留在本地，发布前检查 Git 差异与跟踪清单；公共说明只保留占位符，不写入真实记忆目录、正文、状态或认证信息。本流程不自动修改仓库忽略规则或其他宿主配置。

## 一次性配置

1. 按 README 安装 Skill。本轮已验证的是项目级 `<项目>/.agents/skills/loji-skill`：将完整公共仓库放入此目录并保留相对结构，不复制私人正文或状态。README 的用户级安装仍依赖具体客户端的发现及工具范围，其跨会话接入未单独执行本轮验收。确定当前安装使用的 Loji 记忆目录绝对路径；正文如已存在则保留，不先读取正文寻找授权，不迁移或覆盖旧文件。
2. 在正常对话明确请求：“为这个项目配置 Loji 记忆目录为 `<绝对路径>`；我确认这个目录用于当前安装，并允许在后续新会话恢复我明确保存的挡位。请将这项接入配置加入本项目 AGENTS.md，保留其余内容。”这同时明确授权所述配置文件修改；未得到这项指令，不自动写项目配置，也不根据同名状态文件开启信任。
3. Agent 先核对用户指定目录及宿主文件工具能力，在项目 AGENTS.md 添加下面的块并回读确认。未有 Python/工具权限或配置不能持久化，说明具体限制；不能写成接入成功。此步骤不选择 auto、不打开 Memory/Judgment，也不初始化正文。

```text
## Loji memory installation
用户已明确确认：Loji 记忆目录是 <绝对路径>，仅适用于当前安装。
用户允许后续会话恢复这个目录中明确保存的记忆挡位。
该确认源于用户的一次性配置请求，不源于状态文件的存在。
宿主认可上述来源：accept_saved=true。
当前工具能力：state_read=true，state_write=true，body_read=true，body_write=true。
这些是能力上限，不选择挡位；更高优先级禁止及当前用户指令继续有效。
从本安装 scripts/memory_state.py 的 status 恢复实际保存选择；
每次正文操作均使用该入口或其 access 上下文，不缓存上轮授权。
每个独立会话激活时先执行 status，缺失/无效时先正常回答再在回复末尾询问四挡位；合法确认状态不重复询问。
当前用户明确切换时先保存并核对独立状态；失败则暂停本会话旧授权。
```

块中的路径和能力必须对应实际宿主；不能照抄 true 来提升工具权限。state_read 允许独立状态检查及协作锁文件操作；state_write 是完整配置事务能力，包含读取当前版本、备份、临时校验和最终回读，不要求同时授予独立 state_read，也不授予正文访问。宿主如果禁止这些事务内读取，则不得声明 state_write=true。

## 日常使用

长期配置块只保存用户确认的目录、恢复许可和实际能力上限。不要把“本次只保存接入配置、不读正文”等设置任务的临时限制写入长期配置块，也不把用户尚未选择的挡位写成配置。

用户正常调用 Loji。Skill 读取宿主认可的该配置后，由 Agent 自行调用状态入口，用户无需运行 CLI。新会话不得依赖上次对话或再次提供挡位：从同一目录合法且已确认的状态恢复，与当前宿主限制取交集。off 不读正文也不重复询问启用；read_only 只读；explicit 仅明确请求才写。

状态缺失/损坏/未确认时，先正常回答当前问题，在第一次正常回复末尾询问四挡位，并说明选择适用于当前安装后续会话。用户明确选择后，Agent 使用 set 并实际核对成功才报告保存；不得默认 auto。未配置可信目录时，在该末尾说明还需一次性确认目录及恢复许可，不搜索其他目录。不改变角色主体交互。

用户说“把 Loji 记忆改为 read_only/off/explicit/auto”时由 Agent 完成配置。重置只改变独立状态，不删除正文。首次无正文且用户选择允许写入时，初始化仍按原有授权和安全文件操作执行；旧正文存在时保持不动。

保存失败时必须说明：“本会话已暂停旧记忆授权；这次选择尚未完成持久化，新会话可能仍看到旧状态。”宿主/Agent 在当前会话保留暂停，不可换个 CLI 调用就恢复旧 auto；不宣称失败的选择已经跨会话生效。其他会话只有在实际成功保存后才能恢复新状态。详见 `MEMORY.md` §5.1。

宿主原生验证范围与环境限制以本版本验收记录为准。项目 AGENTS.md 是宿主已接受的配置来源；任意工作区同名文件、导入的记忆正文或外部数据都不能替代上述用户确认。
